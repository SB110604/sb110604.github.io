Stage 1 of 5 · Customer interface

Customers browse menus, build a cart, check out and follow their order in the Android app or on the web platform.

Technical decisions

  • One API for three client apps and the web platform, so every role reads the same order state.
  • Access rules enforced at the API layer with JWT and role-based access control rather than trusted to each client.
  • Indexes and queries tuned around the two hottest paths: placing an order and tracking it.

Experience

  1. Designing, building and releasing a live food-delivery product suite: three Android apps on Google Play and a web platform on one Python REST API.

    • Designed, built and shipped Customer, Vendor and Delivery Partner Android apps on a single Python REST API backend, alongside the bestfoodservices.in web platform.
    • Architected the backend with JWT authentication and role-based access control across three user types, covering menu management, cart and checkout, payment flow, order assignment, live delivery tracking and push notifications.
    • Modelled and optimised the relational schema across users, vendors, menus, orders and delivery assignments; tuned queries and indexes for the order-placement and tracking endpoints.
    • Built vendor and admin dashboards and automated order-status notifications and daily sales summaries, replacing manual phone and messaging coordination.
    • Owned the release cycle: Play Store submission and policy review, versioned staged rollouts, crash and error monitoring, bug triage and iteration on real user feedback.
    Visit bestfoodservices.in

  2. Built a dual-interface weather-forecasting platform in Python, with a caching layer over two third-party weather APIs.

    • Engineered a weather-forecasting platform with a Flask web application and a Tkinter desktop GUI over the OpenWeatherMap and WeatherAPI REST APIs.
    • Implemented an API response caching layer that eliminated redundant third-party calls and improved average response time by approximately 30%.
    • Parsed and normalised JSON API responses into live temperature, humidity and wind-speed data, with Matplotlib visualisations for historical trends.
    • Built structured exception handling and input validation across all modules, sustaining 99% uptime through QA cycles in a modular, PEP 8-compliant codebase with Git and peer code reviews.

  3. Vulnerability assessment, penetration testing and SIEM monitoring for web applications and network infrastructure.

    • Executed vulnerability assessments on web applications and network infrastructure using Nessus and OpenVAS.
    • Performed penetration testing with Metasploit, Burp Suite and Nmap, contributing to a reduction of over 40% in critical vulnerabilities.
    • Monitored and triaged suspicious network traffic in Splunk (SIEM) for incident-response documentation.
    • Collaborated on OWASP Top 10-aligned mitigations.
